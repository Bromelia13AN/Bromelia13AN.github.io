# 个人主页

这是一个不需要构建步骤的静态个人网站。网站文件是 `index.html` 和 `style.css`，GitHub Pages 工作流位于 `.github/workflows/pages.yml`。

## 修改内容

在 `index.html` 中搜索并替换 `Bromelia13AN`、所在位置描述和项目内容。联系入口目前链接到 GitHub 个人主页；可以按需要改成邮箱或其他社交账号。

## 发布

将仓库推送到 GitHub 的 `main` 分支后，Actions 会自动构建并发布到 GitHub Pages。首次发布后，可在仓库的 **Settings → Pages** 查看网站地址。
